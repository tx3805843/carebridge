# Migrations

Timestamped SQL files applied in order via `supabase db push` (see root `README.md` /
`carebridge-roadmap.md` for the full command list). Filename format: `<UTC timestamp>_<name>.sql`,
generated by `pnpm --filter @carebridge/db migrate:new`.

Never edit an already-applied migration — add a new one instead. `pnpm --filter @carebridge/db
migrate:dry-run` (`.github/workflows/migration-dry-run.yml`) runs on every PR touching this
directory and must pass before merge.
